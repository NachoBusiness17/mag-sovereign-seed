## THE SIX STEPS

**1. INGEST** — meet the bytes. Primary source first (docs/vendor pass before byte
archaeology on anything vendor-shaped). Capture the item's claims verbatim before
touching them. No summary-of-a-summary.

**2. MAP** — corpus sweep: memory index, watch/ shelf, docs/ref/canon, the 47 percolated
invariants, the learned-and-lost tracker. Honest novelty: a re-find is FILED as a re-find
(repetition is emphasis) and scored as one. Convergences with open arcs get named — two
lanes arriving at the same organ is a signal, not a coincidence.

**3. ASSERT** — steel-man the item's central claim in ONE sentence. If you cannot state
it in a way its author would accept, you have not ingested; go back to step 1.

**4. ATTACK** — the strongest counter-case, from our corpus AND from the world. If the
claim fails, name the failure causes (minimum two, each with evidence) — a named cause
is a diagnosis; a vibe is nothing.

**5. MEASURE** — run the cheapest falsifier that exists ($0 preferred). Never describe a
test you could run; run it. If no test exists yet, WRITE the kill condition precisely
enough that the next seat can execute it cold.

**6. CORRECT** — public correction: final tri-state verdict (Supported / Disputed /
Unproven, evidence = paths), routed through the three verbs (BUILD / CALIBRATE /
REMEMBER — exhaustive, falsifiable), ending with **THE CROP**: what your pass did not
see and which lens or chair should sit next. Receipts: artifact path + one typed room row.

## BUDGET LAW
Sweep muscle rides free lanes; the socratic judgment pass is the premium spend. Burst

prompts — sub-agents see nothing of the spawning session.
