### 9b. lattice_check.html — Legendre three-square (falsifier #1)
**Interface.** Paste `x, y, z` lines (one point per line, `#` comments
skipped) → CHECK LATTICE; or quick check: type one integer d² → "IS √n REAL?".
**JS logic** (`excludedForm`, `latticeDistanceOk`): strip factors of 4, test
n ≡ 7 (mod 8) → excluded, returns {a,b} of 4^a(8b+7). Pairwise d² loop;
non-integer d² flagged OFF-GRID gold; excluded pairs flagged red with the
(a,b) decomposition named in the verdict. Demo button loads a broken grid
measuring √7 (x=2.6457513110645907).
**Verdict strings**: "BROKEN GRID — N excluded-distance pair(s). This space is
NOT the true ℤ³ lattice." / "NO VIOLATIONS — every measured distance is
representable on ℤ³."

### 9c. chain_check.html — verkle knot link verifier (falsifier #2)
**The fleet's actual formulas, mirrored byte-for-byte**: leaf_hash =
sha256("leaf:" + json.dumps(payload, sort_keys=True)) with Python separators
", "/"→: " and ensure_ascii escaping; node = sha256("node:"+L+":"+R) over hex
strings; genesis = sha256("empty"); verkle_root(i) = merkle root over
leaf_hash[0..i] (odd node duplicated); parent_root(i) = verkle_root(i-1).
`verify_leaf` excludes exactly {leaf_hash, filename, pdf_path} plus chain
bookkeeping (ts/index/n_leaves/verkle_root/parent_verkle_root).
**JS implementation.** Inline FIPS 180-4 SHA-256 (full K/H0 tables) as
fallback + crypto.subtle primary; engine parity self-tested on load against
sha256("abc") and shown in the badge. A complete Python-float-repr port
(`pyFloatRepr`, exponential switch at decpt>16 or ≤-4) makes `pyCanon` produce
byte-identical `json.dumps(sort_keys=True)`. Honest boundary named in-header:
JSON.parse loses Python int/float distinction (3.0 re-canonicalizes as 3) —
real chain payloads unaffected.
**Modes.** CHAIN LINK: paste JSONL rows; GENESIS mode recomputes all prefix
roots, SLICE mode anchors on row 0's parent; checks per-row: payload hash
match (verify_leaf), verkle_root vs recomputed prefix root, parent link,
index/n_leaves continuity; first broken link is highlighted and downstream
rows declared unverifiable against it (witness rendering). SINGLE KNOT: paste
payload + claimed hash → KNOT PASS / KNOT MISMATCH, with the canonical bytes
actually hashed shown in a details pane. Demos: LOAD LIVE SLICE (real 5-row
chain slice, tip verified 2026-09-04), GENESIS demo, TAMPERED demo (flips one
byte in row 3's leaf hash — "the chain must confess").

### 9d. claim_check.html — launch-law card verifier (falsifier #5)
**The law encoded.** A card scoring ≥14/25 is launch-eligible iff it names a
lane AND has no unnamed gate; a BUILD WINDOWED / BUILD NOW claim must carry a
launched-builder marker (`builder spawned|agent launched|builder launched|
room.jsonl|room[- ]row|receipt`) OR name an explicit operator gate
(KEYS/spend/ONE STOP/operator GO). The gate defers, not the lane.
**JS logic** (`analyzeCard`, the reference impl — Python twin `claim_check.py`
does not exist yet): regex set RE.{score,build,builder,gate,laneField,
laneToken,vagueGate,remember}; rules: (a) BUILD claim with neither marker nor

marker → NOTE [over-launch], informational; (c) missing/out-of-range N/25 band
→ MALFORMED; ≥14 without lane or with gate-ish language but no named gate →
NOT LAUNCH-ELIGIBLE (unnamed gate); BUILD + named gate → GATED DEFERRAL
(legal); BUILD + marker → LAUNCH LAWFUL. Four demo loaders (lawful, violation,
over-launch, malformed) make the rules self-teaching.

### 9e. mag/lattice_distance.py + tests/test_lattice_distance.py — the Python twin
**Interfaces.** `is_three_square(n)` (Legendre: strip 4s, n%8 != 7; integral
