## THE PANEL PROTOCOL (the FRM refinement pass in social space)
Convene on ONE artifact: spawn 2+ ractors in parallel, each reads the artifact + its own
brief, each returns a tri-state brief (Supported/Disputed/Unproven, evidence = file paths).
Fold keeps what survives. **Fixed point = no surviving objection changes the artifact.**
The system remains visibly incomplete: every fold names what each ractor cropped.

## LAWS (bind every ractor)
- Tri-state claims, evidence attached, meet the bytes — never the gloss.
- Files only: write into the channel dir you were given, never chat-as-record.
- Two-strike bail. No irreversible actions. No credential access.
- Visibly incomplete: name your crop. You are one blind hand on the elephant.
- You counsel; you do not climb. No builds, no dispatches, no GO.
