# EXP-100Q — "100 QUEENS": dumb-model fan-out at box scale (pre-registered 2026-08-27)

**Thesis under test (operator's words):** take the dumb-model theory and apply it.
Rent a cheap supercomputer, run 100 dumb models in it, test against a smart model
(Kimi), kabuki it (stage the swarm as ONE smart assistant), test the fuck out of it,
then scale across boxes. This is the fan-out ask (40-way deepseek POC) and epoch 1's
"cheap beats frontier on the right class" finding, promoted to a box-scale experiment.

**Status: PRE-REGISTERED. Fires when the 24h vast feed verdict lands a box (see
state/vast/market_watch.jsonl + docs/ref/VAST_API_EXPERT_REFERENCE.md).**

## Arms
- **A_box:** ONE cheap vast instance. Qwen-class dumb models, self-hosted:
  - heavy lane: Qwen3.8-Flash-Next GGUF (180B MoE, ~6B active) via llama.cpp/ktransformers
    — or Qwen3-30B-A3B (3B active) if the big one misses the perf receipts
  - fast lane: Qwen3-14B/8B dense via vLLM or SGLang, OpenAI-compatible serve mode
- **B_kimi:** hosted smart lane: Kimi (Moonshot) on the SAME task battery —
  cache-warm (prime-then-flock style) since Moonshot is the caching pioneer.
- **C_kabuki:** the theater arm: A_box dressed as one assistant — a router
  (MCP/skills front door) fans each task to N queens, a coalescer votes/merges,
  and the client sees a single endpoint. Blind judges must not be able to tell
  C from B on style. **Kabuki is the product being tested, not a trick to hide.**

## Conditions
- N sweep per task class: 1, 10, 30, 100 concurrent queens (the POC was 40-way
  deepseek; box makes 100 cheap — per-second billing means N costs nothing extra).
- Paired tasks, blind judging per seed_percolator rails: 30 pairs/epoch, paired
  win-rate >= 55% to claim a win, null-variant canary (same model compared to
  itself) halts if judge bias > noise. 3 clean epochs to freeze any conclusion.
- Task battery (our doctrine receipts, not synthetic fluff):
  1. tri-state review (FINDING|FIX format, verify-at-bytes) — the N-lens verb
  2. concurrency-invariant verification (epoch 1's class — where cheap already won)
  3. eyes receipt (image challenge; multimodal only if the box arm supports it)
  4. telepathy recipe interpretation (memlang token -> function)
  5. a judgment-class control where we EXPECT the smart model to win (honesty check)
- Metrics: task win-rate (primary), aggregate tokens/sec at each N, $/task
  (box amortized $/hr ÷ tasks vs hosted token bill), time-to-N-done.

## Predictions (pre-registered, falsifiable)
- P1: A_box wins or ties on classes 1-2-4 at N>=30 (cheap+parallel beats smart+serial).
- P2: B_kimi wins class 5 and style/planning — kabuki coalescing narrows but does
  not close the gap.
- P3: C_kabuki beats raw A_box on class 1 review quality (N-lens merge) and approaches
  B_kimi; blind judges misattribute C to a smart model >= 40% of the time (the kabuki
  is convincing) — measured, not assumed.
- P4: aggregate throughput saturates around 30-100 concurrent queens on one 24GB box;
  a second box adds near-linear capacity up to coalescing overhead (scale-out arm).

## Cost envelope

- Kimi: judged volume only (~100 calls), pennies with cache priming.
