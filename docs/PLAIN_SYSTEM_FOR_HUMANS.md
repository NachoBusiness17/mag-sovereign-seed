# The System, Plainly

*A tight translation. Each piece: what it is, how it works, what it can't do.*

**1. The Memory (the chain).**
Every important thing the machine learns is written down once, permanently, in a file that
can't be edited secretly. Everything else reads from that file. That's how the machine
remembers its decisions, and how two running copies of it stay on the same page.
*The catch:* the file is the machine's whole identity. If it's lost, the machine loses
itself. That's why there's a backup (piece 6).

**2. The Routine (the loop).**
About every 90 seconds the machine checks in. If the computer is busy, it waits. If there's
real work, it does it. If there's nothing, it stays quiet. It writes a note about every
check-in.
*The catch:* it only does work that already exists (a task or a real question). It does not
make work out of nothing.

**3. The Quality Check (the gate).**
Before anything the machine learns gets saved, it's scored on whether it's a real answer or
noise. Low-score answers are thrown out — recorded as a miss, never saved.
*The catch:* the scoring is a simple rule, not a perfect judge. A good answer that breaks the
rule's assumptions could be thrown out.

**4. The Machine Guard (the ceiling).**
The machine refuses to take work when the computer is already near its limit. It waits
instead of piling on.
*The catch:* it only measures one number (processor load). Other kinds of strain aren't seen.

**5. The Evolving Knowledge (the wave).**
The machine's saved ideas are treated like a breeding population: the strongest are combined
and varied to make new ideas, which get tested by the same quality check. The good new ones
get saved.
*The catch:* "strongest" is judged by a simple rule, not by real-world results yet.

**6. The Seal (the backup).**
A verified, signed copy of the memory is made on a schedule and checked to make sure the
copy is intact. The machine can be rebuilt from it on a new computer.
*The catch:* today the copy lives on the same machine as the original. One physical drive can
still take both.

**7. The Key (who are you?).**
To recognize its person, the machine asks them to rank 14 plain statements about what
matters. Their ranking is compared to the person's recorded ranking with a standard math
formula. High match = same values = same person.
*The catch:* someone who knows the person well could copy the ranking. It's a strong signal,
not a lock.

**8. The Steering (plant a direction).**
To point the machine, you plant a seed of intent instead of giving a command. The machine
leans toward it without being ordered.
*The catch:* a seed only leans. It can't force specific behavior.
