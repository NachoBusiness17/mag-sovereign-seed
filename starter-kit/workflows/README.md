# WORKFLOWS - the shapes, runnable anywhere

The workflow shapes as self-contained specs: harness-agnostic (they run
as scripts in any workflow engine, or as sequential prompts in fresh
chat contexts - the shapes, not the tooling, are the method). The
workflow-shaper skill card (skills/workflow-shaper/) is the composer;
these are the two standing compositions worth keeping whole.

| shape | file |
|---|---|
| the wide dig | 8 lanes around any subject, one synthesizer |
| the gap analysis | one auditor per surface, verdicts verified against bytes |

Both compositions live by the salvage law (report items as they land)
and the fresh-eyes law (every synthesis gets a cold read before it
ships).
