# SKILLS - the method cards

Each card is a directory holding SKILL.md (the discovery shape most agent
runtimes expect; flat .md files are often invisible to them). Cards are
distilled method - rename every one into your own vocabulary when you
adopt it (the jargon-map law).

| card | what it does |
|---|---|
| receipt-filer/ | file the receipt before claiming done |
| lane-runner/ | run one card unattended, checkpointed, headless |
| workflow-shaper/ | cut a multi-agent question into the five shapes |
| ractor-lenses/ | the eight standing lenses for hostile review |

The three reactive-loop cards (conversation-miner, profile-grower,
law-minter) live in agent/ and mount per integrations/hermes/README.md.
