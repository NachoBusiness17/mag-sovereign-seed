# Ractor Lenses

Eight lenses ride the subject in parallel; each returns findings with
path:line evidence. No lens that cannot cite is heard.

## The library

| lens | hunts for |
|---|---|
| accuracy | the falsifier that kills each claim; evidence that does not exist |
| operations | what breaks at 3am; the missing checkpoint, the silent failure |
| economics | the price of everything, priced honestly; spend that buys nothing |
| communication | what the audience will misunderstand; jargon leaks |
| dogfood | what the system already holds that the plan rebuilds (wire, not build) |
| lineage | what was tried before and what it cost; repeated-mistake detection |
| logic | contradictions; conclusions their premises cannot carry |
| security | how a stranger abuses this; trust boundaries and supply chains |

## The discipline

1. Lenses ride IN PARALLEL (fresh contexts, one lens each).
2. HOSTILE SECOND PASS: every finding's evidence is re-read by a context
   that did not produce it. Killings are banked, not re-litigated.
3. STEER ONCE: weakened findings go back to their lens with the critique;
   one revision round.
4. TRIANGULATE: survivors merge through one voice; the dissent stays
   visible in the record.
5. MOONSHOTS PROPOSE, NOTHING EXECUTES WITHOUT THE OWNER'S GO.

## Run

Give each lens the subject, the laws (no em-dashes, never fabricate,
cite path:line), and the result contract: findings (what / evidence /
severity / fix), headline, confidence.
